# IntentWire Admin Dashboard

This is the admin dashboard for the IntentWire platform, built with Next.js 15, React 19, and Tailwind CSS.

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Running the Application

```bash
# Development
npm run dev

# Production build
npm run build
npm start
```

Open [http://localhost:3001](http://localhost:3001) with your browser to see the result.

## Features

- Company Listings Management
- Review Management
- User Management
- Category and Subcategory Management
- Blog Management
- Data Request Management
